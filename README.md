# Рекомендация тарифов мобильного оператора

**Задача.** Оператор связи предлагает два тарифа. По поведению клиента нужно подобрать подходящий тариф. Требуемая точность — не ниже 0,75.

**Что сделано.** Подготовка данных, разбиение на обучающую, валидационную и тестовую выборки, сравнение моделей, проверка лучшей модели на тесте, сравнение с Dummy-моделью.

**Стек.** Python, pandas, scikit-learn, Matplotlib, Seaborn

**Результат.** accuracy 0,82 против 0,70 у Dummy-модели

**Ноутбуки:**
